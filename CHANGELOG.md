# CHANGELOG

## 0.2.0

- Added immutable conflict resolutions and resolution sets. Each resolution records its conflict, decision, optional accepted value and review note.
- Supported decisions are `accepted_candidate`, `deferred` and `manual_review_required`.

## 0.1.0

- Initial conflict model
- Added conflict candidates and conflict sets
- Added conflict detector orchestration
- Added relationship cardinality conflict rule
- Added extensible conflict rule definition mechanism
- Added JSON conflict rule loading
